# e3d-creative

Creative direction engine: turns a creative brief into distinct, defensible
creative directions (concept, script, storyboard, shot list, visual-style
direction) without rendering any pixels. Product-agnostic, reusable across
every FutCo product.

Being built phase by phase from `docs/e3d-creative-engine-spec.md` via
[spec2code](https://github.com/spacepacket1/spec2code). This README will be
replaced with real usage docs in that spec's final phase.
